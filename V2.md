Логика, которую надо добавить:

При показе вопроса бот всегда отправляет его id.
/delete от администратора просит ввести id вопроса.
Бот находит вопрос по id, показывает текст для подтверждения.
После подтверждения удаляет запись из questions.
Сразу удаляет все связанные записи из user_progress.
Если этот вопрос был у кого-то текущим в памяти, очищает last_question.
/resetdb сначала просит подтверждение, потом удаляет файл БД или все данные и заново создаёт таблицы.

Для безопасности лучше сделать /resetdb только через двойное подтверждение, а /delete — только для одного id за раз.
