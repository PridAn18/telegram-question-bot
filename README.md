# Telegram Question Bot

Бот для закрепления знаний: показывает вопрос, пользователь отвечает своими
словами, бот присылает правильный ответ. Один Python-процесс на aiogram 3.x,
работает через Long Polling, данные хранит в SQLite.

## Возможности

- Случайный выбор вопросов, уже показанные не повторяются до конца цикла.
- После прохождения всех вопросов прогресс сбрасывается и цикл начинается заново.
- Категории вопросов, которые создаются автоматически.
- Административные команды: добавление, импорт/экспорт CSV, состояние, логи.

## Команды пользователя

| Команда   | Описание                                     |
|-----------|----------------------------------------------|
| `/start`  | Приветствие и кнопка «Начать»                |

Сценарий: бот показывает вопрос → пользователь отвечает → бот присылает
правильный ответ с кнопкой «Далее» → следующий вопрос.

## Административные команды

Доступ определяет список `ADMIN_IDS`. Пример: `ADMIN_IDS=919410233,123456789`.

| Команда   | Описание                                              |
|-----------|-------------------------------------------------------|
| `/add`    | Добавить вопрос через FSM: вопрос → ответ → категория |
| `/import` | Импортировать CSV-файл `category,question,answer`     |
| `/export` | Экспортировать базу в CSV того же формата             |
| `/delete` | Удалить вопрос по ID (с подтверждением и очисткой прогресса пользователей) |
| `/resetdb`| Полный сброс базы (безвозвратно, с двойным подтверждением) |
| `/health` | Статус, аптайм, счётчики, размер базы, память, версия |
| `/logs`   | Последние строки `logs/bot.log` или сам файл          |

> ⚠️ `/resetdb` удаляет **все** вопросы, категории и прогресс пользователей
> **безвозвратно**. Команда запрашивает двойное подтверждение, но будь
> осторожен: восстановить данные после сброса невозможно. Перед сбросом
> сделай резервную копию через `/export`.

ID каждого вопроса отображается рядом с текстом (например, `#15`), чтобы
администратор мог удалить нужный вопрос через `/delete`.

Пример CSV для импорта:

```csv
category,question,answer
Linux,Что делает ls?,Показывает содержимое каталога.
Сети,Что такое TCP?,Transmission Control Protocol.
```

Файл можно выгрузить из Excel/LibreOffice/Google Sheets, отредактировать и
импортировать обратно. Дубликаты пропускаются благодаря `UNIQUE(category_id, question)`.

## Структура проекта

```
bot.py                     # точка входа
config.py                  # загрузка конфигурации (.env)
database.py                # работа с SQLite (4 таблицы)
states.py                  # FSM-состояния
keyboards.py               # inline-клавиатуры
handlers/start.py          # /start
handlers/questions.py      # основной сценарий «вопрос → ответ → далее»
handlers/admin.py          # админ-команды
services/question_service.py  # алгоритм выдачи вопросов
services/import_service.py    # импорт CSV
utils/logger.py            # логирование (stdout + logs/bot.log)
utils/constants.py         # константы проекта
data/                      # SQLite-база (создаётся автоматически)
logs/                      # файлы логов (создаются автоматически)
install.sh                 # автоматическая установка
update.sh                  # обновление проекта
telegram-bot.service       # systemd unit (путь подставляется в install.sh)
```

## Конфигурация

Конфигурация задаётся только переменными окружения (`.env`):

| Переменная     | Описание                                  |
|----------------|-------------------------------------------|
| `BOT_TOKEN`    | Токен бота из @BotFather                  |
| `ADMIN_IDS`    | ID администраторов через запятую          |
| `DATABASE_PATH`| Путь к SQLite-базе (по умолчанию `data/questions.db`) |
| `LOG_PATH`     | Путь к лог-файлу (по умолчанию `logs/bot.log`) |

Токены и секреты в коде отсутствуют.

## Установка на VPS

1. Публикуем репозиторий на GitHub.
2. На VPS (Debian/Ubuntu) копируем `install.sh` и запускаем:

```bash
sudo ./install.sh
sudo ./install.sh "https://github.com/USER/telegram-question-bot.git"
```

Скрипт сам установит системные пакеты, склонирует репозиторий, создаст
виртуальное окружение, зависимости, `.env`, systemd-сервис, запустит сервис
и включит автозапуск. `BOT_TOKEN` и `ADMIN_IDS` запрашиваются интерактивно,
если не переданы аргументами/переменными окружения.

## Обновление

```bash
sudo ./update.sh
```

Скрипт выполняет `git pull`, обновляет зависимости, перезапускает сервис.
Изменения структуры БД применяются автоматически при старте
(`CREATE TABLE IF NOT EXISTS`).

## Контроль работы

```bash
systemctl status telegram-bot
journalctl -u telegram-bot -f
```

Или через Telegram: `/health`, `/logs`.

## Требования

- Python 3.12+
- aiogram 3.x
- SQLite (встроенный)
- python-dotenv

Около 40–70 МБ RAM в обычной работе. Потребление памяти не зависит от количества
вопросов — SQLite хранит данные на диске и подгружает только нужные записи.
